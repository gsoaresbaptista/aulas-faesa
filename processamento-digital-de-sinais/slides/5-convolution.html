Introdução

  • A análise de sistemas lineares e invariantes no tempo (LCIT) baseia-se na decomposição de sinais.
  • A ferramenta fundamental para determinar a saída de um sistema a partir de uma entrada qualquer é a convolução.
  • O ponto de partida é conhecer a "impressão digital" do sistema: a Resposta ao Impulso Unitário $h(t)$.

A Resposta $\text{ }h(t)\text{ }$ ao Impulso Unitário

  • Definição: É a saída de um sistema quando a entrada é um impulso de Dirac $\delta(t)$.
  • Para sistemas descritos por:

$$Q(D)y(t) = P(D)x(t)$$

  • Onde $Q(D)$ tem ordem $N$ e $P(D)$ tem ordem $M$ ($M \le N$).
  • Se $M < N$, a resposta é composta pelos modos característicos:

$$h(t) = \big( c_1 e^{\lambda_1 t} + c_2 e^{\lambda_2 t} + \dots + c_N e^{\lambda_N t} \big) u(t)$$

  • As constantes $c_i$ são determinadas pelas condições iniciais geradas pelo impulso em $t=0$.

Exemplo 1: Determinação de $\text{ }h(t)$

Sistema: $(D^2 + 5D + 6)y(t) = (D + 1)x(t)$

Forma Diferencial: $\frac{d^2y}{dt^2} + 5\frac{dy}{dt} + 6y(t) = \frac{dx}{dt} + x(t)$

Passo 1: Forma funcional ($t > 0$)

Equação característica: $\lambda^2 + 5\lambda + 6 = 0 \implies (\lambda + 2)(\lambda + 3) = 0$

Raízes: $\lambda_1 = -2, \lambda_2 = -3$

Forma funcional: $f(t) = c_1 e^{-2t} + c_2 e^{-3t}$ Resposta candidata: $h(t) = f(t)u(t)$

Exemplo 1: Derivadas de Distribuição

Precisamos balancear os impulsos na equação diferencial. Primeira derivada $\dot{h}(t)$:

$$\dot{h}(t) = \dot{f}(t)u(t) + f(0)\delta(t)$$

Segunda derivada $\ddot{h}(t)$:

$$\ddot{h}(t) = \ddot{f}(t)u(t) + \dot{f}(0)\delta(t) + f(0)\dot{\delta}(t)$$

Propriedade

Usamos a amostragem: $g(t)\delta(t) = g(0)\delta(t)$.

Exemplo 1: Balanceamento de Singularidades

Substituindo na ED: $\ddot{h}(t) + 5\dot{h}(t) + 6h(t) = \dot{\delta}(t) + \delta(t)$

Agrupando termos singulares (Sobras):

$$f(0)\dot{\delta}(t) + [\dot{f}(0) + 5f(0)]\delta(t) = 1\dot{\delta}(t) + 1\delta(t)$$

Comparando coeficientes:

  • Para $\dot{\delta}(t)$: $f(0) = 1$
  • Para $\delta(t)$: $\dot{f}(0) + 5f(0) = 1 \implies \dot{f}(0) + 5(1) = 1 \implies \dot{f}(0) = -4$

Exemplo 1: Sistema e Resultado Final

Aplicando as condições iniciais em $f(t) = c_1 e^{-2t} + c_2 e^{-3t}$:

  1. $f(0) = c_1 + c_2 = 1$
  2. $\dot{f}(0) = -2c_1 - 3c_2 = -4$

Resolvendo o sistema:

$c_1 = 1 - c_2 \implies -2(1 - c_2) - 3c_2 = -4 \implies -2 - c_2 = -4 \implies \mathbf{c_2 = 2}$

$c_1 = 1 - 2 \implies \mathbf{c_1 = -1}$

Expressão Final:

$$\boxed{h(t) = (-e^{-2t} + 2e^{-3t})u(t)}$$

Exemplo 2: O Caso $\text{ }M = N$

Sistema: $(D + 2)y(t) = (3D + 5)x(t)$

Ordem: Saída ($N=1$), Entrada ($M=1$).

Regra das Ordens

Como $N=M$, o sistema tem resposta instantânea.

Forma: $h(t) = A\delta(t) + y_n(t)u(t)$

Onde $A = \frac{\text{coef. maior ordem } x}{\text{coef. maior ordem } y} = \frac{3}{1} = 3$.

Exemplo 2: Derivação e Equilíbrio

Substituindo $h(t) = 3\delta(t) + Ke^{-2t}u(t)$ na ED $\dot{h}(t) + 2h(t) = 3\dot{\delta}(t) + 5\delta(t)$:

Singularidades: $3\dot{\delta}(t) + [y_n(0) + 2(3)]\delta(t) = 3\dot{\delta}(t) + 5\delta(t)$

Comparando $\delta(t)$: $y_n(0) + 6 = 5 \implies y_n(0) = -1 \implies K = -1$

Expressão Final:

$$\boxed{h(t) = 3\delta(t) - e^{-2t}u(t)}$$

Resposta de Estado Nulo

  • Refere-se à saída $y(t)$ quando o sistema parte do repouso (condições iniciais nulas).
  • Utiliza o Princípio da Superposição.

Decomposição do Sinal

Qualquer entrada $x(t)$ pode ser vista como uma soma de pulsos retangulares estreitos. No limite $\Delta\tau \to 0$, esses pulsos tornam-se impulsos de Dirac escalonados.

A Integral de Convolução

Pela linearidade e invariância no tempo, a resposta total é a soma das respostas a cada impulso individual:

$$y(t) = \int_{-\infty}^{\infty} x(\tau)h(t - \tau) d\tau$$

Simbolicamente representada por:

$$y(t) = x(t) * h(t)$$

Impressão Digital

Uma vez que conhecemos $h(t)$, podemos prever o comportamento do sistema para qualquer entrada $x(t)$.

Propriedades da Convolução

  • Comutativa: $x_1(t) * x_2(t) = x_2(t) * x_1(t)$
  • Distributiva: $x_1(t) * [x_2(t) + x_3(t)] = x_1(t) * x_2(t) + x_1(t) * x_3(t)$
  • Associativa: $x_1(t) * [x_2(t) * x_3(t)] = [x_1(t) * x_2(t)] * x_3(t)$
  • Deslocamento: Se $x_1(t) * x_2(t) = c(t)$, então:

$$x_1(t - T_1) * x_2(t - T_2) = c(t - T_1 - T_2)$$

Propriedades da Convolução II

  • Convolução com Impulso: $x(t) * \delta(t) = x(t)$
  • Propriedade da Largura: Se $x_1$ tem largura $T_1$ e $x_2$ tem largura $T_2$, a largura da saída é $T_1 + T_2$.

Causalidade e Limites Práticos

Sistemas reais são causais: a resposta não ocorre antes da entrada ($h(t) = 0$ para $t < 0$). Se a entrada $x(t)$ também inicia em $t = 0$:

A integral simplifica seus limites, pois o produto $x(\tau)h(t - \tau)$ só é diferente de zero no intervalo $0 \le \tau \le t$:

$$\boxed{y(t) = \int_{0}^{t} x(\tau)h(t - \tau) d\tau, \quad t \geq 0}$$

Exemplo 5: Cálculo da Saída

Dados: $h(t) = e^{-2t}u(t)$ e $x(t) = e^{-t}u(t)$.

  1. Substituição: $y(t) = \int_{0}^{t} e^{-\tau} e^{-2(t-\tau)} d\tau$
  2. Simplificação: $y(t) = e^{-2t} \int_{0}^{t} e^{-\tau} e^{2\tau} d\tau = e^{-2t} \int_{0}^{t} e^{\tau} d\tau$
  3. Integração: $y(t) = e^{-2t} [e^t - e^0] = e^{-2t}(e^t - 1)$
  4. Resultado: $y(t) = (e^{-t} - e^{-2t})u(t)$

Exemplo 6: Entrada Degrau

Dados: $h(t) = 6e^{-t}u(t)$ e $x(t) = 2u(t)$.

  1. Substituição: $y(t) = \int_{0}^{t} 2 \cdot 6e^{-(t-\tau)} d\tau$
  2. Simplificação: $y(t) = 12e^{-t} \int_{0}^{t} e^{\tau} d\tau$
  3. Integração: $y(t) = 12e^{-t} (e^t - 1)$
  4. Resultado: $\boxed{y(t) = 12(1 - e^{-t})u(t)}$

Sistemas Interconectados

Conexão em Paralelo

As saídas são somadas:

$$\mathbf{h_p(t) = h_1(t) + h_2(t)}$$

Conexão em Série (Cascata)

A saída do primeiro é a entrada do segundo:

$$\mathbf{h_c(t) = h_1(t) * h_2(t)}$$

Sistemas Interconectados

Exemplo 3: Raiz em Zero

Sistema: $D(D+2)y(t) = (D+4)x(t) \implies \ddot{y} + 2\dot{y} = \dot{x} + 4x$

Ordens: $N=2, M=1 \implies N > M$ (sem termo impulsivo).

  1. Raízes: $\lambda(\lambda+2)=0 \implies 0, -2$.
  2. Forma: $f(t) = c_1 + c_2 e^{-2t}$.
  3. Balanceamento: $f(0)\dot{\delta} + [\dot{f}(0) + 2f(0)]\delta = 1\dot{\delta} + 4\delta$.
  4. CI: $f(0) = 1$ e $\dot{f}(0) + 2(1) = 4 \implies \dot{f}(0) = 2$.
  5. Sistema: $c_1+c_2=1$ e $-2c_2=2 \implies c_2=-1, c_1=2$.
  6. Resultado: $\boxed{h(t) = (2 - e^{-2t})u(t)}$

Exemplo 4: Raízes Repetidas

Sistema: $(D^2 + 2D + 1)y(t) = Dx(t)$

Raízes: $(\lambda + 1)^2 = 0 \implies \lambda = -1$ (dupla).

  1. Forma: $f(t) = (c_1 + c_2 t)e^{-t}$.
  2. Balanceamento: $f(0)\dot{\delta} + [\dot{f}(0) + 2f(0)]\delta = 1\dot{\delta} + 0\delta$.
  3. CI: $f(0) = 1$ e $\dot{f}(0) + 2(1) = 0 \implies \dot{f}(0) = -2$.
  4. Cálculo: $f(0) = c_1 = 1$; $\dot{f}(t) = c_2 e^{-t} - (c_1+c_2t)e^{-t} \implies \dot{f}(0) = c_2 - c_1 = -2 \implies c_2 = -1$.
  5. Resultado: $\boxed{h(t) = (1 - t)e^{-t}u(t)}$
