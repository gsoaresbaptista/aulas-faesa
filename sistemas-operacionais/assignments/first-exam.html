5. Sobre a implementação de Threads, existe um debate clássico entre gerenciar as threads no Espaço do Usuário ou no Espaço do Núcleo. Qual é a principal DESVANTAGEM das threads implementadas puramente no Espaço do Usuário? (1,0 ponto)
a) Elas são muito mais lentas para serem criadas do que as threads de núcleo.
b) Exigem uma transição custosa (TRAP) para o Modo Núcleo a cada chaveamento de contexto.
c) Se uma thread fizer uma chamada de sistema bloqueante (como aguardar digitação do teclado), todo o processo e suas outras threads ficarão paralisados.
d) Elas não permitem o compartilhamento de variáveis globais entre si.

7. No código abaixo, duas threads são criadas para incrementar uma mesma variável global simultaneamente, visando alcançar o valor de 2 milhões: (1,0 ponto)

#include <stdio.h>
#include <pthread.h>

long contador = 0;

void* incremento(void* arg) {
    for (int i = 0; i < 1000000; i++) {
        contador++;
    }
    return NULL;
}

int main() {
    pthread_t t1, t2;

    pthread_create(&t1, NULL, incremento, NULL);
    pthread_create(&t2, NULL, incremento, NULL);

    pthread_join(t1, NULL);
    pthread_join(t2, NULL);

    printf("Resultado real: %ld\n", contador);
    return 0;
}
