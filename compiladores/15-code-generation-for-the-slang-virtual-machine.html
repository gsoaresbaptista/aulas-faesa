Compiladores IV - Análise Semântica Lab - Geração de Código para a SlangVM

Introdução15.1

No laboratório anterior de implementação, finalizamos o analisador sintático estrutural do Slang. Ao terminar o segundo roteiro prático, o compilador já consegue fazer duas coisas importantes:

  • transformar o código-fonte em tokens com o modo lex;
  • transformar o código-fonte em uma AST completa com o modo parse.

Isso significa que o front-end do nosso compilador já está funcionando. O programa abaixo, por exemplo:

fn main(args: void) -> void {
    value: int = 5
    print(value)
}

já pode ser lido, tokenizado, parseado e impresso como árvore. Mas ele ainda não pode ser executado.

Neste laboratório, vamos fechar essa lacuna. O objetivo agora é pegar a AST produzida pelo parser e gerar código para uma máquina virtual de pilha, a SlangVM.

O fluxo final será:

Na prática, ao final deste laboratório, você poderá executar:

./build/compiler code programa.slang > programa.slasm
./build/slang-vm programa.slasm

O primeiro comando usa o compilador para gerar assembly textual da VM. O segundo comando executa esse assembly.

O que muda nesta etapa15.2

Até agora, o executável principal aceitava dois modos:

./build/compiler lex arquivo.slang
./build/compiler parse arquivo.slang

Agora adicionaremos um terceiro modo:

./build/compiler code arquivo.slang

Esse novo modo fará o seguinte:

  1. inicializar o parser;
  2. construir a AST do programa;
  3. percorrer a AST;
  4. escrever assembly da SlangVM em stdout.

Além disso, o projeto passará a compilar também um segundo executável:

./build/slang-vm arquivo.slasm

Esse executável é a máquina virtual que interpreta o assembly gerado.

O assembly da SlangVM15.3

A SlangVM é uma máquina de pilha. Isso significa que as instruções geralmente empilham valores, removem valores do topo da pilha e colocam resultados de volta no topo.

Por exemplo, a expressão:

1 + 2 * 3

deve ser gerada como:

push 1
push 2
push 3
mul
add

Essa sequência funciona porque:

  1. push 1 empilha o número 1;
  2. push 2 empilha o número 2;
  3. push 3 empilha o número 3;
  4. mul remove 2 e 3, calcula 6 e empilha o resultado;
  5. add remove 1 e 6, calcula 7 e empilha o resultado.

Essa estratégia é muito conveniente para um compilador didático, porque evita que precisemos escolher registradores temporários.

Instruções que vamos gerar15.4

O gerador de código usará principalmente as instruções abaixo.

Instrução Papel
push valor Empilha uma constante
get_local n Lê o slot local n
set_local n Escreve no slot local n
pop Remove o topo da pilha
add, sub, mul, div, mod Operações aritméticas
neg Negação numérica
not Negação lógica
eq, ne, lt, le, gt, ge Comparações
label nome Marca uma posição do programa
jump nome Salto incondicional
jump_if_false nome Salto condicional
call argc nome Chamada de função
ret Retorno de função
print Impressão do topo da pilha
halt Encerra a VM

Essas instruções são suficientes para traduzir o subconjunto do Slang que já temos no parser: variáveis, expressões, if, loop, break, continue, return, funções e chamadas.

Adicionando a SlangVM ao projeto15.6

Neste laboratório, a VM será usada como alvo de execução. Para não misturar a implementação do parser, do gerador de código e da VM em um único problema grande demais, a implementação da VM deve ser adicionada como um módulo separado do projeto.

Crie as pastas:

include/vm/
src/vm/

Dentro delas, adicione os arquivos da VM fornecidos com o material da aula:

include/vm/value.h
include/vm/chunk.h
include/vm/vm.h
include/vm/assembler.h
include/vm/debug.h
src/vm/chunk.c
src/vm/vm.c
src/vm/assembler.c
src/vm/debug.c
src/vm/main.c

Antes de integrar o gerador de código, vale entender o papel de cada grupo de arquivos:

  • value.h define os valores que a VM consegue manipular;
  • chunk.h e chunk.c armazenam bytecode e constantes;
  • vm.h e vm.c executam as instruções;
  • assembler.h e assembler.c transformam assembly textual em bytecode;
  • debug.h e debug.c ajudam a imprimir bytecode durante depuração;
  • src/vm/main.c cria o executável slang-vm.

Neste ponto, o compilador ainda não gera nada para a VM. Estamos apenas preparando o alvo.

Criando a interface do gerador15.7

Agora vamos adicionar o módulo responsável por traduzir AST para assembly da VM.

Crie o arquivo include/compiler/codegen.h:

#ifndef COMPILER_CODEGEN_H_
#define COMPILER_CODEGEN_H_

#include <stdbool.h>
#include <stdio.h>
#include "compiler/ast.h"

bool codegen_generate(FILE *stream, const AstNode *program);

#endif

A interface é pequena de propósito. O gerador recebe:

  • um FILE *stream, para decidir onde escrever o assembly;
  • a raiz da AST, que deve ser um AST_PROGRAM.

Se a geração terminar corretamente, a função retorna true. Se encontrar algo que ainda não sabemos gerar, retorna false.

O estado interno do gerador15.8

O gerador precisa lembrar algumas informações enquanto percorre a AST.

Primeiro, ele precisa mapear variáveis para slots locais. Por exemplo:

fn main(args: void) -> void {
    x: int = 5
    y: int = x + 1
}

Aqui, args pode ocupar o slot 0, x pode ocupar o slot 1 e y pode ocupar o slot 2.

Segundo, ele precisa criar labels para saltos. Um if, por exemplo, precisa de uma label para o else e outra para o fim do comando.

Terceiro, ele precisa controlar break e continue. Esses comandos só fazem sentido dentro de um loop, então o gerador guarda a label de início e a label de fim do laço atual.

Por isso, usaremos as estruturas abaixo em src/compiler/codegen.c:

#define MAX_SYMBOLS 256
#define MAX_LOOPS 64

typedef struct {
    const char *start;
    int length;
    int slot;
} Symbol;

typedef struct {
    int start_label;
    int end_label;
} LoopLabels;

typedef struct {
    FILE *stream;
    Symbol symbols[MAX_SYMBOLS];
    int symbol_count;
    int next_slot;
    LoopLabels loops[MAX_LOOPS];
    int loop_count;
    int next_label;
    bool had_error;
} Codegen;

Implementando src/compiler/codegen.c15.9

Agora crie o arquivo src/compiler/codegen.c.

Vamos construí-lo por partes para entender a lógica antes de ver o arquivo completo.

Includes e declarações iniciais15.9.1

Comece com:

#include <stdbool.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include "compiler/codegen.h"

#define MAX_SYMBOLS 256
#define MAX_LOOPS 64

typedef struct {
    const char *start;
    int length;
    int slot;
} Symbol;

typedef struct {
    int start_label;
    int end_label;
} LoopLabels;

typedef struct {
    FILE *stream;
    Symbol symbols[MAX_SYMBOLS];
    int symbol_count;
    int next_slot;
    LoopLabels loops[MAX_LOOPS];
    int loop_count;
    int next_label;
    bool had_error;
} Codegen;

static void gen_declaration(Codegen *codegen, const AstNode *node);
static void gen_statement(Codegen *codegen, const AstNode *node);
static void gen_expression(Codegen *codegen, const AstNode *node);

Essas três funções serão a base da geração:

  • gen_declaration lida com declarações do nível atual;
  • gen_statement lida com comandos;
  • gen_expression lida com expressões.

Essa separação segue a mesma divisão conceitual do parser.

Tokens, labels e símbolos15.9.2

Agora adicione as funções auxiliares:

static bool token_equals(Token token, const char *text) {
    int length = (int)strlen(text);
    return token.length == length && memcmp(token.start, text, length) == 0;
}

static void print_token(FILE *stream, Token token) {
    fprintf(stream, "%.*s", token.length, token.start);
}

static int new_label(Codegen *codegen) {
    return codegen->next_label++;
}

token_equals será útil para reconhecer casos especiais, como main e print.

new_label gera números únicos para labels como L0, L1, L2.

Agora precisamos mapear variáveis para slots:

static int find_symbol(Codegen *codegen, Token name) {
    for (int i = codegen->symbol_count - 1; i >= 0; i--) {
        Symbol symbol = codegen->symbols[i];
        if (symbol.length == name.length && memcmp(symbol.start, name.start, name.length) == 0) {
            return symbol.slot;
        }
    }

    fprintf(stderr, "Erro de geracao: variavel '%.*s' nao declarada.\n", name.length, name.start);
    codegen->had_error = true;
    return 0;
}

static int declare_symbol(Codegen *codegen, Token name) {
    if (codegen->symbol_count == MAX_SYMBOLS) {
        fprintf(stderr, "Erro de geracao: muitas variaveis locais.\n");
        codegen->had_error = true;
        return 0;
    }

    int slot = codegen->next_slot++;
    codegen->symbols[codegen->symbol_count++] = (Symbol){name.start, name.length, slot};
    return slot;
}

Essa tabela de símbolos é simples. Ela não faz análise semântica completa. Ela apenas responde: “em qual slot local esta variável está guardada?”

Literais de string e nomes de função15.9.3

Strings precisam de um cuidado especial. O token da string inclui as aspas do código-fonte, e o assembly também precisa receber uma string entre aspas.

Adicione:

static void emit_string_literal(FILE *stream, Token token) {
    fputc('"', stream);
    for (int i = 1; i < token.length - 1; i++) {
        char c = token.start[i];
        if (c == '"' || c == '\\') {
            fputc('\\', stream);
        }
        fputc(c, stream);
    }
    fputc('"', stream);
}

static void emit_function_label(FILE *stream, Token name) {
    fputs("fn_", stream);
    print_token(stream, name);
}

Todas as funções do Slang serão emitidas com prefixo fn_. Assim, a função Slang factorial vira a label fn_factorial no assembly.

Gerando funções e blocos15.10

Um bloco é uma sequência de declarações. Portanto, sua geração é direta:

static void gen_block(Codegen *codegen, const AstNode *block) {
    for (int i = 0; i < block->children.count; i++) {
        gen_declaration(codegen, block->children.items[i]);
    }
}

Uma função precisa criar uma label, registrar seus parâmetros como slots locais e gerar seu corpo:

static void gen_function(Codegen *codegen, const AstNode *function) {
    fputs("label ", codegen->stream);
    emit_function_label(codegen->stream, function->token);
    fputc('\n', codegen->stream);

    codegen->symbol_count = 0;
    codegen->next_slot = 0;
    codegen->loop_count = 0;

    for (int i = 0; i < function->children.count; i++) {
        declare_symbol(codegen, function->children.items[i]->token);
    }

    gen_block(codegen, function->first);
    fputs("push null\nret\n", codegen->stream);
}

O push null final é um retorno padrão. Ele garante que uma função sem return explícito ainda retorne algum valor para a VM.

Gerando variáveis e atribuições15.11

Uma declaração de variável avalia o inicializador e guarda o resultado em um slot:

static void gen_var_decl(Codegen *codegen, const AstNode *node) {
    int slot = declare_symbol(codegen, node->token);
    gen_expression(codegen, node->first);
    fprintf(codegen->stream, "set_local %d\n", slot);
}

Uma atribuição é parecida, mas o slot já deve existir:

case AST_ASSIGN:
    gen_expression(codegen, node->first);
    fprintf(codegen->stream, "set_local %d\npop\n", find_symbol(codegen, node->token));
    break;

Usamos pop na atribuição para remover da pilha o valor que acabou de ser gravado. Isso mantém a pilha limpa após comandos.

Gerando expressões15.12

Literais são os casos mais simples:

case AST_NUMBER:
    fputs("push ", codegen->stream);
    print_token(codegen->stream, node->token);
    fputc('\n', codegen->stream);
    break;

case AST_BOOL:
    fputs(node->token.type == TOK_KW_TRUE ? "push true\n" : "push false\n", codegen->stream);
    break;

Identificadores viram leitura de slot local:

case AST_IDENTIFIER:
    fprintf(codegen->stream, "get_local %d\n", find_symbol(codegen, node->token));
    break;

Operações binárias geram primeiro o lado esquerdo, depois o lado direito, depois a instrução da operação:

gen_expression(codegen, node->first);
gen_expression(codegen, node->second);

Depois disso, o operador decide qual instrução emitir:

case TOK_PLUS: fputs("add\n", codegen->stream); break;
case TOK_MINUS: fputs("sub\n", codegen->stream); break;
case TOK_STAR: fputs("mul\n", codegen->stream); break;
case TOK_SLASH: fputs("div\n", codegen->stream); break;
case TOK_PERCENT: fputs("mod\n", codegen->stream); break;
case TOK_EQ: fputs("eq\n", codegen->stream); break;
case TOK_BANG_EQ: fputs("ne\n", codegen->stream); break;
case TOK_LT: fputs("lt\n", codegen->stream); break;
case TOK_LT_EQ: fputs("le\n", codegen->stream); break;
case TOK_GT: fputs("gt\n", codegen->stream); break;
case TOK_GT_EQ: fputs("ge\n", codegen->stream); break;

Curto-circuito de and e or15.13

Operadores lógicos merecem atenção especial.

Para and, se o lado esquerdo já for falso, não precisamos avaliar o lado direito. Esse comportamento é chamado de curto-circuito.

if (node->token.type == TOK_AND) {
    int end_label = new_label(codegen);
    gen_expression(codegen, node->first);
    fprintf(codegen->stream, "jump_if_false L%d\npop\n", end_label);
    gen_expression(codegen, node->second);
    fprintf(codegen->stream, "label L%d\n", end_label);
    return;
}

Para or, se o lado esquerdo já for verdadeiro, também não precisamos avaliar o lado direito:

if (node->token.type == TOK_OR) {
    int right_label = new_label(codegen);
    int end_label = new_label(codegen);
    gen_expression(codegen, node->first);
    fprintf(codegen->stream, "jump_if_false L%d\njump L%d\nlabel L%d\npop\n", right_label, end_label, right_label);
    gen_expression(codegen, node->second);
    fprintf(codegen->stream, "label L%d\n", end_label);
    return;
}

Esse é um bom exemplo de por que a geração de código não é apenas uma troca direta de nó por instrução. Algumas construções precisam de controle de fluxo.

Gerando if15.14

Um if precisa de duas labels:

  • uma para o else;
  • outra para o fim do comando.
static void gen_if(Codegen *codegen, const AstNode *node) {
    int else_label = new_label(codegen);
    int end_label = new_label(codegen);

    gen_expression(codegen, node->first);
    fprintf(codegen->stream, "jump_if_false L%d\npop\n", else_label);
    gen_statement(codegen, node->second);
    fprintf(codegen->stream, "jump L%d\nlabel L%d\npop\n", end_label, else_label);
    if (node->third != NULL) {
        gen_statement(codegen, node->third);
    }
    fprintf(codegen->stream, "label L%d\n", end_label);
}

O campo first guarda a condição, second guarda o bloco do then, e third guarda o else, se existir.

Gerando loop, break e continue15.15

Um laço precisa saber para onde voltar e para onde sair.

static void gen_loop(Codegen *codegen, const AstNode *node) {
    if (codegen->loop_count == MAX_LOOPS) {
        fprintf(stderr, "Erro de geracao: lacos aninhados demais.\n");
        codegen->had_error = true;
        return;
    }

    int start_label = new_label(codegen);
    int false_label = new_label(codegen);
    int end_label = new_label(codegen);
    codegen->loops[codegen->loop_count++] = (LoopLabels){start_label, end_label};

    fprintf(codegen->stream, "label L%d\n", start_label);
    if (node->first != NULL) {
        gen_expression(codegen, node->first);
        fprintf(codegen->stream, "jump_if_false L%d\npop\n", false_label);
    }

    gen_statement(codegen, node->second);
    fprintf(codegen->stream, "jump L%d\n", start_label);

    if (node->first != NULL) {
        fprintf(codegen->stream, "label L%d\npop\n", false_label);
    }
    fprintf(codegen->stream, "label L%d\n", end_label);
    codegen->loop_count--;
}

Com isso, continue vira um salto para start_label, e break vira um salto para end_label.

Gerando chamadas de função15.16

Chamadas são geradas avaliando todos os argumentos e depois emitindo call.

for (int i = 0; i < node->children.count; i++) {
    gen_expression(codegen, node->children.items[i]);
}

fprintf(codegen->stream, "call %d ", node->children.count);
emit_function_label(codegen->stream, node->first->token);
fputc('\n', codegen->stream);

O caso especial é print. Em vez de ser uma função Slang real, vamos tratá-la como uma primitiva da VM:

if (node->first != NULL && node->first->kind == AST_IDENTIFIER && token_equals(node->first->token, "print")) {
    for (int i = 0; i < node->children.count; i++) {
        gen_expression(codegen, node->children.items[i]);
        fputs("print\n", codegen->stream);
    }
    fputs("push null\n", codegen->stream);
    return;
}

Depois de imprimir, empilhamos null porque chamadas usadas como expressão precisam deixar algum valor na pilha.

Arquivo completo de codegen.c15.17

Depois de entender as partes, substitua src/compiler/codegen.c pelo arquivo completo abaixo:

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include "compiler/codegen.h"

#define MAX_SYMBOLS 256
#define MAX_LOOPS 64

    const char *start;
    int length;
    int slot;
} Symbol;

typedef struct {
    int start_label;
    int end_label;
} LoopLabels;

typedef struct {
    FILE *stream;
    Symbol symbols[MAX_SYMBOLS];
    int symbol_count;
    int next_slot;
    LoopLabels loops[MAX_LOOPS];
    int loop_count;
    int next_label;

static void gen_declaration(Codegen *codegen, const AstNode *node);
static void gen_statement(Codegen *codegen, const AstNode *node);

}

static int new_label(Codegen *codegen) {
    return codegen->next_label++;
}

static int find_symbol(Codegen *codegen, Token name) {
    for (int i = codegen->symbol_count - 1; i >= 0; i--) {
        Symbol symbol = codegen->symbols[i];
        if (symbol.length == name.length && memcmp(symbol.start, name.start, name.length) == 0) {
            return symbol.slot;
        }
    }

    fprintf(stderr, "Erro de geracao: variavel '%.*s' nao declarada.\n", name.length, name.start);
    codegen->had_error = true;

}

static int declare_symbol(Codegen *codegen, Token name) {
    if (codegen->symbol_count == MAX_SYMBOLS) {
        fprintf(stderr, "Erro de geracao: muitas variaveis locais.\n");
        codegen->had_error = true;
        return 0;
    }

    int slot = codegen->next_slot++;
    codegen->symbols[codegen->symbol_count++] = (Symbol){name.start, name.length, slot};
    return slot;
}

static void emit_string_literal(FILE *stream, Token token) {
    fputc('"', stream);
    for (int i = 1; i < token.length - 1; i++) {
        char c = token.start[i];
        if (c == '"' || c == '\\') {
            fputc('\\', stream);
        }
        fputc(c, stream);
    }
    fputc('"', stream);
}

static void emit_function_label(FILE *stream, Token name) {
    fputs("fn_", stream);
    print_token(stream, name);
}

static const AstNode *find_main(const AstNode *program) {
    for (int i = 0; i < program->children.count; i++) {
        const AstNode *child = program->children.items[i];
        if (child->kind == AST_FUNCTION && token_equals(child->token, "main")) {
            return child;
        }
    }
    return NULL;
}

static bool program_has_top_level_code(const AstNode *program) {
    for (int i = 0; i < program->children.count; i++) {
        if (program->children.items[i]->kind != AST_FUNCTION) {
            return true;
        }
    }
    return false;
}

static void gen_block(Codegen *codegen, const AstNode *block) {
    for (int i = 0; i < block->children.count; i++) {
        gen_declaration(codegen, block->children.items[i]);
    }
}

static void gen_function(Codegen *codegen, const AstNode *function) {
    fputs("label ", codegen->stream);
    emit_function_label(codegen->stream, function->token);
    fputc('\n', codegen->stream);

    codegen->symbol_count = 0;
    codegen->next_slot = 0;
    codegen->loop_count = 0;

    for (int i = 0; i < function->children.count; i++) {
        declare_symbol(codegen, function->children.items[i]->token);
    }

    gen_block(codegen, function->first);
    fputs("push null\nret\n", codegen->stream);
}

static void gen_var_decl(Codegen *codegen, const AstNode *node) {
    int slot = declare_symbol(codegen, node->token);
    gen_expression(codegen, node->first);
    fprintf(codegen->stream, "set_local %d\n", slot);
}

static void gen_if(Codegen *codegen, const AstNode *node) {
    int else_label = new_label(codegen);
    int end_label = new_label(codegen);

    gen_expression(codegen, node->first);
    fprintf(codegen->stream, "jump_if_false L%d\npop\n", else_label);
    gen_statement(codegen, node->second);
    fprintf(codegen->stream, "jump L%d\nlabel L%d\npop\n", end_label, else_label);
    if (node->third != NULL) {
        gen_statement(codegen, node->third);
    }
    fprintf(codegen->stream, "label L%d\n", end_label);
}

static void gen_loop(Codegen *codegen, const AstNode *node) {
    if (codegen->loop_count == MAX_LOOPS) {
        fprintf(stderr, "Erro de geracao: lacos aninhados demais.\n");
        codegen->had_error = true;
        return;
    }

    int start_label = new_label(codegen);
    int false_label = new_label(codegen);
    int end_label = new_label(codegen);
    codegen->loops[codegen->loop_count++] = (LoopLabels){start_label, end_label};

    fprintf(codegen->stream, "label L%d\n", start_label);
    if (node->first != NULL) {
        gen_expression(codegen, node->first);
        fprintf(codegen->stream, "jump_if_false L%d\npop\n", false_label);
    }

    gen_statement(codegen, node->second);
    fprintf(codegen->stream, "jump L%d\n", start_label);

    if (node->first != NULL) {
        fprintf(codegen->stream, "label L%d\npop\n", false_label);
    }
    fprintf(codegen->stream, "label L%d\n", end_label);
    codegen->loop_count--;
}

static void gen_call(Codegen *codegen, const AstNode *node) {
    if (node->first != NULL && node->first->kind == AST_IDENTIFIER && token_equals(node->first->token, "print")) {
        for (int i = 0; i < node->children.count; i++) {
            gen_expression(codegen, node->children.items[i]);
            fputs("print\n", codegen->stream);
        }
        fputs("push null\n", codegen->stream);
        return;
    }

    for (int i = 0; i < node->children.count; i++) {
        gen_expression(codegen, node->children.items[i]);
    }

    if (node->first == NULL || node->first->kind != AST_IDENTIFIER) {
        fprintf(stderr, "Erro de geracao: chamada indireta nao suportada.\n");
        codegen->had_error = true;
        return;
    }

    fprintf(codegen->stream, "call %d ", node->children.count);
    emit_function_label(codegen->stream, node->first->token);
    fputc('\n', codegen->stream);
}

static void gen_binary(Codegen *codegen, const AstNode *node) {
    if (node->token.type == TOK_AND) {
        int end_label = new_label(codegen);
        gen_expression(codegen, node->first);
        fprintf(codegen->stream, "jump_if_false L%d\npop\n", end_label);
        gen_expression(codegen, node->second);
        fprintf(codegen->stream, "label L%d\n", end_label);
        return;
    }

    if (node->token.type == TOK_OR) {
        int right_label = new_label(codegen);
        int end_label = new_label(codegen);
        gen_expression(codegen, node->first);
        fprintf(codegen->stream, "jump_if_false L%d\njump L%d\nlabel L%d\npop\n", right_label, end_label, right_label);
        gen_expression(codegen, node->second);
        fprintf(codegen->stream, "label L%d\n", end_label);
        return;
    }

    gen_expression(codegen, node->first);
    gen_expression(codegen, node->second);

    switch (node->token.type) {
        case TOK_PLUS: fputs("add\n", codegen->stream); break;
        case TOK_MINUS: fputs("sub\n", codegen->stream); break;
        case TOK_STAR: fputs("mul\n", codegen->stream); break;
        case TOK_SLASH: fputs("div\n", codegen->stream); break;
        case TOK_PERCENT: fputs("mod\n", codegen->stream); break;
        case TOK_EQ: fputs("eq\n", codegen->stream); break;
        case TOK_BANG_EQ: fputs("ne\n", codegen->stream); break;
        case TOK_LT: fputs("lt\n", codegen->stream); break;
        case TOK_LT_EQ: fputs("le\n", codegen->stream); break;
        case TOK_GT: fputs("gt\n", codegen->stream); break;
        case TOK_GT_EQ: fputs("ge\n", codegen->stream); break;
        default:
            fprintf(stderr, "Erro de geracao: operador binario nao suportado.\n");
            codegen->had_error = true;
            break;
    }
}

static void gen_expression(Codegen *codegen, const AstNode *node) {
    if (node == NULL || codegen->had_error) {
        return;
    }

    switch (node->kind) {
        case AST_BINARY:
            gen_binary(codegen, node);
            break;
        case AST_UNARY:
            gen_expression(codegen, node->first);
            fputs(node->token.type == TOK_MINUS ? "neg\n" : "not\n", codegen->stream);
            break;
        case AST_CALL:
            gen_call(codegen, node);
            break;
        case AST_IDENTIFIER:
            fprintf(codegen->stream, "get_local %d\n", find_symbol(codegen, node->token));
            break;
        case AST_NUMBER:
            fputs("push ", codegen->stream);
            print_token(codegen->stream, node->token);
            fputc('\n', codegen->stream);
            break;
        case AST_STRING:
            fputs("push ", codegen->stream);
            emit_string_literal(codegen->stream, node->token);
            fputc('\n', codegen->stream);
            break;
        case AST_CHAR:
            fputs("push ", codegen->stream);
            print_token(codegen->stream, node->token);
            fputc('\n', codegen->stream);
            break;
        case AST_BOOL:
            fputs(node->token.type == TOK_KW_TRUE ? "push true\n" : "push false\n", codegen->stream);
            break;
        default:
            fprintf(stderr, "Erro de geracao: expressao nao suportada.\n");
            codegen->had_error = true;
            break;
    }
}

static void gen_statement(Codegen *codegen, const AstNode *node) {
    if (node == NULL || codegen->had_error) {
        return;
    }

    switch (node->kind) {
        case AST_BLOCK:
            gen_block(codegen, node);
            break;
        case AST_VAR_DECL:
            gen_var_decl(codegen, node);
            break;
        case AST_IF:
            gen_if(codegen, node);
            break;
        case AST_LOOP:
            gen_loop(codegen, node);
            break;
        case AST_RETURN:
            if (node->first != NULL) {
                gen_expression(codegen, node->first);
            } else {
                fputs("push null\n", codegen->stream);
            }
            fputs("ret\n", codegen->stream);
            break;
        case AST_BREAK:
            if (codegen->loop_count == 0) {
                fprintf(stderr, "Erro de geracao: break fora de laco.\n");
                codegen->had_error = true;
            } else {
                fprintf(codegen->stream, "jump L%d\n", codegen->loops[codegen->loop_count - 1].end_label);
            }
            break;
        case AST_CONTINUE:
            if (codegen->loop_count == 0) {
                fprintf(stderr, "Erro de geracao: continue fora de laco.\n");
                codegen->had_error = true;
            } else {
                fprintf(codegen->stream, "jump L%d\n", codegen->loops[codegen->loop_count - 1].start_label);
            }
            break;
        case AST_ASSIGN:
            gen_expression(codegen, node->first);
            fprintf(codegen->stream, "set_local %d\npop\n", find_symbol(codegen, node->token));
            break;
        case AST_EXPR_STMT:
            gen_expression(codegen, node->first);
            fputs("pop\n", codegen->stream);
            break;
        default:
            gen_expression(codegen, node);
            fputs("pop\n", codegen->stream);
            break;
    }
}

static void gen_declaration(Codegen *codegen, const AstNode *node) {
    if (node->kind != AST_FUNCTION) {
        gen_statement(codegen, node);
    }
}

static void gen_entry(Codegen *codegen, const AstNode *program) {
    fputs("label __entry\n", codegen->stream);
    codegen->symbol_count = 0;
    codegen->next_slot = 0;
    codegen->loop_count = 0;

    for (int i = 0; i < program->children.count; i++) {
        const AstNode *child = program->children.items[i];
        if (child->kind != AST_FUNCTION) {
            gen_declaration(codegen, child);
        }
    }

    fputs("push null\nret\n", codegen->stream);
}

bool codegen_generate(FILE *stream, const AstNode *program) {
    Codegen codegen = {0};
    codegen.stream = stream;

    const AstNode *main_function = find_main(program);
    bool has_main = main_function != NULL;
    bool has_top_level = program_has_top_level_code(program);

    if (has_main) {
        for (int i = 0; i < main_function->children.count; i++) {
            fputs("push null\n", stream);
        }
        fprintf(stream, "call %d fn_main\nhalt\n", main_function->children.count);
    } else {
        fputs("call 0 __entry\nhalt\n", stream);
    }

    for (int i = 0; i < program->children.count; i++) {
        const AstNode *child = program->children.items[i];
        if (child->kind == AST_FUNCTION) {
            gen_function(&codegen, child);
        }
    }

    if (has_top_level || !has_main) {
        gen_entry(&codegen, program);
    }

    return !codegen.had_error;
}

static char* read_file(const char* path) {
    FILE* file = fopen(path, "rb");
    if (file == NULL) {
        fprintf(stderr, "Erro: Não foi possível abrir o arquivo \"%s\".\n", path);
        exit(74);
    }

    fseek(file, 0L, SEEK_END);
    size_t fileSize = ftell(file);
    rewind(file);

    char* buffer = (char*)malloc(fileSize + 1);
    if (buffer == NULL) {
        fprintf(stderr, "Erro: Memória insuficiente para ler \"%s\".\n", path);
        exit(74);
    }

    size_t bytesRead = fread(buffer, sizeof(char), fileSize, file);
    if (bytesRead < fileSize) {
        fprintf(stderr, "Erro: Falha na leitura do arquivo \"%s\".\n", path);
        exit(74);
    }

    buffer[bytesRead] = '\0';
    fclose(file);
    return buffer;
}

static int run_lexer_mode(const char *source) {
    Lexer lexer;
    lexer_init(&lexer, source);

    Token token;
    do {
        token = lexer_next_token(&lexer);
        token_println(&token);
    } while (token.type != TOK_EOF && token.type != TOK_ERROR);

    return 0;
}

static int run_parser_mode(const char *source) {
    Parser parser;
    parser_init(&parser, source, stderr);

    AstNode *program = parser_parse(&parser);
    if (program == NULL) {
        return 65;
    }

    ast_print(stdout, program);
    ast_free(program);
    return 0;
}

static int run_codegen_mode(const char *source) {
    Parser parser;
    parser_init(&parser, source, stderr);

    AstNode *program = parser_parse(&parser);
    if (program == NULL) {
        return 65;
    }

    bool ok = codegen_generate(stdout, program);
    ast_free(program);
    return ok ? 0 : 65;
}

int main(int argc, char* argv[]) {
    if (argc != 3) {
        fprintf(stderr, "Uso: compiler <lex|parse|code> <arquivo>\n");
        return 64;
    }

    char* source = read_file(argv[2]);

    int result = 0;

    if (strcmp(argv[1], "lex") == 0) {
        result = run_lexer_mode(source);
    } else if (strcmp(argv[1], "parse") == 0) {
        result = run_parser_mode(source);
    } else if (strcmp(argv[1], "code") == 0) {
        result = run_codegen_mode(source);
    } else {
        fprintf(stderr, "Uso: compiler <lex|parse|code> <arquivo>\n");
        free(source);
        return 64;
    }

    free(source);
    return result;
}

A única ideia nova aqui é run_codegen_mode. Ele é muito parecido com run_parser_mode, mas em vez de imprimir a AST, chama codegen_generate.

O que esta etapa resolve15.25

Com este laboratório, o compilador deixa de ser apenas uma ferramenta de análise e passa a produzir código executável para uma máquina alvo.

Antes, o fluxo terminava na AST. Agora, o fluxo termina em execução:

Esse é o ponto em que o projeto se torna, de fato, um compilador completo dentro do escopo didático da disciplina.

Limitações conscientes15.26

Ainda existem simplificações importantes:

  • não há análise semântica completa de tipos;
  • não há escopo lexical sofisticado para blocos aninhados;
  • strings são suportadas principalmente como valores imprimíveis;
  • a VM usa endereços pequenos em um byte para saltos e chamadas;
  • print é tratado como primitiva especial, não como função Slang comum.

Essas limitações são aceitáveis neste marco porque o objetivo é consolidar a ideia central de geração de código. A partir daqui, cada uma delas pode virar uma melhoria futura.

Próximos Passos15.27

Com o compilador gerando código para a SlangVM, as próximas extensões naturais seriam:

  • adicionar análise semântica antes da geração de código;
  • validar tipos de expressões e retornos de função;
  • implementar escopos por bloco;
  • adicionar otimizações simples, como constant folding;
  • trocar o assembly textual por um bytecode binário real.

O ponto principal, porém, já foi alcançado: agora temos um ciclo completo de compilação e execução para a linguagem Slang.
