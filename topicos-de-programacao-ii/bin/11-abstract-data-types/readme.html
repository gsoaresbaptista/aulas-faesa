Study Guide Assets1

This folder contains the complete support material for the lesson 11 - abstract data types.md.

Each step contains:

  • the source code for that version of the project
  • an inputs/ folder with sample test cases
  • an outputs/ folder with the expected outputs generated from those inputs

The intended study flow is:

  1. compile the current step
  2. run the program with one of the provided inputs
  3. compare the result with the corresponding file in outputs/
  4. only then move to the next step
